# Daily LeetCode

個人 LeetCode 每日練習記錄，搭配 AI 輔助練習流程。

## 使用方式

安裝 [leetcode-skill plugin](https://github.com/BIBIOTA/yuki-marketplace/tree/master/plugins/leetcode-skill) 後，在 Claude Code 中使用以下指令：

```
/leetcode <url>          # 開始練習指定題目
/hint                    # 取得漸進式提示
/run                     # 執行測試
/submit                  # 提交並評估解法
/finish                  # 結束本題，更新進度
/next                    # 依弱點推薦下一題
```

詳細說明見 [CLAUDE.md](./CLAUDE.md)。

## 進度追蹤

- 練習記錄：`.leetcode/performance/log.md`
- 弱點分析：`.leetcode/performance/weak-areas.md`
- Pattern 筆記：`.leetcode/notes/`
